# Security Policy

## Supported Versions

We take security seriously and actively support only the latest stable version of Zapret Launcher. 
Older versions are not supported and may contain unpatched vulnerabilities.

| Version | Status |
| ------- | ---------
| 3.2.3.4 | Actively supported; receives security updates |
| 3.2.3.3 and earlier | Not supported; may contain vulnerabilities |

**Recommendation:** Always use the latest version. You can check for updates within the launcher or on the official website.

---

## Vulnerability Report

If you have discovered a security issue, please report it responsibly.

### Where to report
- **Bot:** [@zapret_launcher_bot](https://t.me/zapret_launcher_bot)

### What to expect

| Stage | Timeline | Description |
|-------|-----------|-------------|
| **Acknowledgment** | Within 24 hours | We will confirm receipt of your report |
| **Investigation** | 3–7 days | We will analyze and verify the issue |
| **Fix and Release** | As soon as possible | A fix will be prepared and released in a new version |
| **Public Disclosure** | After the fix is ​​released | We will include your name (if you wish) in the changelog |

### Scope of application

Following fall within the scope:
- Zapret Launcher application (all modules)
- Telegram Proxy implementation
- Implementation of the zapret core

Following is **out of scope**:
- Third-party dependency (**WinDivert**) — please report issues to the respective developer ([bol-van](https://github.com/bol-van))

---

## Security recommendations for users

To ensure your safety while using Zapret Launcher:

1. Always download from **official** sources:
   - Official website: https://zapret-launcher.ru
   - GitHub: https://github.com/avaxngard/zapret-launcher
   - GitLab: https://gitlab.com/tweenkrage/zapret-launcher
   - Never download from third-party websites or forums

2. Keep your launcher **up to date**:
   - Enable automatic update checks
   - Install updates as soon as they are released

---

## Data Collection Policy

Zapret Launcher collects a **minimum** amount of data to improve the product:

| Data Type | Purpose |
|-----------|---------|
| Version information | Checking for updates |
| Usage statistics | Product improvement |
| IP address | Never collected |
| Personal data | Never collected |

All collected data is anonymized and used solely to improve the launcher. You can opt out of telemetry in the settings.
